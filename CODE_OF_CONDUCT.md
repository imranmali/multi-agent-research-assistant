# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Our pledge

We pledge to make participation in our community a harassment-free experience for everyone,
regardless of:

- age, body size, or visible or invisible disability
- ethnicity, sex characteristics, gender identity and expression
- level of experience, education, or socio-economic status
- nationality, personal appearance, race, caste or color
- religion, or sexual identity and orientation

We expect everyone to be respectful and constructive and to assume good intent. Harassment,
personal attacks and publishing others' private information are not acceptable.

## Scope

The code of conduct applies in all project spaces: issues, pull requests, discussions and reviews.
It also applies when someone represents the project in public.

## Enforcement

Report unacceptable behaviour privately to the maintainer,
[@imranmali](https://github.com/imranmali), for example through a
[private security advisory](https://github.com/imranmali/multi-agent-research-assistant/security/advisories/new)
if no other private channel is available.

All reports are reviewed promptly and in confidence. Maintainers follow the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
which range from a correction to a permanent ban.
